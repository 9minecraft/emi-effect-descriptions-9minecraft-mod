# EMI Effect Descriptions — Know What Every Potion Effect Does

EMI Effect Descriptions 9minecraft Mod adds status effect guides for EMI. This mod gives every status effect in the game its own helpful screen with clear explanations. You can quickly see which foods, potions, and blocks give you positive buffs or harmful conditions without checking an outside guide.

\t Shows plain explanations for every status effect in the game and your installed mods. \t Displays every food, potion, tipped arrow, and block that can give you a specific effect.

## What this build is

An unofficial rebuild of **moechakucha**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
